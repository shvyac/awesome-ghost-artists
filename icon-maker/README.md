# Icon Forge

iPhone の Safari で使える、アイコン／ロゴ作成 Web アプリ（`index.html` 1ファイル、ビルド不要）。

- 文字・絵文字（2行可）、12種のフォント、太さ・大きさ・影・縁取り
- 背景：単色／グラデーション／放射、模様（ドット・斜線・方眼）、光沢
- 写真やロゴ画像の重ね合わせ
- 形のプレビュー：iOS（スクワークル）／角丸／円／四角、ホーム画面での見え方
- 書き出し：iOS アイコン 1024px、apple-touch-icon 180px、透過ロゴ 1024px、丸アバター 512px
- 設定はブラウザ（localStorage）に自動保存

## 使い方

GitHub Pages を有効にするか、任意の静的ホスティングに `index.html` を置いて iPhone の Safari で開きます。
Safari の共有ボタン →「ホーム画面に追加」でアプリのように使えます。

書き出した画像は長押し →「"写真"に保存」。ショートカットアプリの「ホーム画面に追加」でアイコン画像として使えます。
