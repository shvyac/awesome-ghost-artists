# Awesome Ghost Artists

[日本語版はこちら / Japanese](README.ja.md)

Apple Music links for emerging “ghost artist” / delivery-native indie scenes — often AI-assisted or AI-forward projects with thin public identity.

## How clustering works

Clusters are **not** strict genre labels. They come from:

1. Apple Music “similar artists” graph isolation (Soft Melodic ↔ Wa Spiritual barely cross within ~2 hops)
2. Curator listening splits in playlists ([shvyac.female.ai](https://music.apple.com/jp/playlist/shvyac-female-ai/pl.u-ZmblKjaczA1oGB), [shvyac.hard.ai](https://music.apple.com/jp/playlist/shvyac-hard-ai/pl.u-PDb4o6VukaG9Xq))

| Cluster | Entry artists | Feel |
| --- | --- | --- |
| **A. Soft Melodic** | Piyoking / 4Rabbit | Soft love-pop, J-POP/R&B-ish, female-leaning vocals, high release volume |
| **B. Hard Edge** | RAGGAREA | Ragga / street / high-energy |
| **C. Wa Spiritual** | YORISHIRO – 神の宿る場 | Norito, dragon gods, yōkai, Ainu, ritual ambient |

Within each cluster: **Entry → Center → Nearby → Graph periphery** (or motif groups for C).

## Cross-cutting tags (not clusters)

Apply alongside A/B/C when known:

- `AI-primary` — artist self-IDs as AI creator (e.g. 音奏羽アリナ)
- `AI-assist` — AI used in production; humans still central (e.g. AI AINU)
- `AI-unknown` — default when unclear
- `collab-unit` — multi-name projects (e.g. Bluebird Queen × Super Sloth Man)
- `local-dialect` — dialect / regional novelty tracks

### Explicit AI notes
- **音奏羽アリナ** — profile: “AIクリエイター”
- **3Dミュージック** — SNS: songs “AIに作ってもらった”
- **AI AINU** — AI production assist; vocals human
